# automatic translation

一个网页翻译脚本。默认自动翻译整个网页，点击悬浮球可翻译或还原原文；支持划词翻译、智能识别、朗读、拖动悬浮按钮、语言方向设置、翻译服务切换和自定义 GET 接口。

脚本文件：`automatic translation.txt`

## 功能

- 默认翻译方向：英语 -> 简体中文。
- 打开网页后按“默认自动翻译”设置自动翻译整个页面。
- 点击悬浮球直接翻译当前网页，再点一下还原原文，不再弹出任何面板。
- 悬浮球可拖动，位置自动保存。
- 图标 5 秒无操作后淡化，透明度可设置。
- 支持启用/关闭悬浮翻译。
- 支持划词翻译：选中文字后出现小翻译按钮，点击查看译文。
- 支持划词智能识别：例如选中中文翻译成英文，选中英文翻译成中文。
- 支持划词朗读：可以朗读选中的原文或翻译结果。
- 支持微软翻译、Google 翻译、MyMemory 翻译和自定义接口。
- 支持设置语言 A 和语言 B，例如语言 A 选“所有语言”、语言 B 选“简体中文”。

## 安装

1. 安装脚本猫（ScriptCat）。
2. 新建用户脚本。
3. 将 `automatic translation.txt` 的全部内容复制进去。
4. 保存并启用脚本。
5. 打开网页，右上角会出现“译”按钮。

脚本的配置界面由脚本猫提供。Tampermonkey、Violentmonkey 等管理器不识别脚本开头的 `==UserConfig==` 配置声明，不会显示配置界面，只能使用默认设置，因此推荐使用脚本猫。

## 使用

### 悬浮球

- 页面右上角有一个“译”按钮。
- 点击“译”：开始翻译当前网页。
- 翻译完成后再次点击：还原成原文。
- 按住“译”按钮可拖动位置，松开后自动保存。
- 5 秒无操作后图标会按设置的透明度淡化。

如果“默认自动翻译”开着，网页加载后会自动翻译，此时点击悬浮球是还原原文；如果“默认自动翻译”关着，网页加载后不会翻译，点击悬浮球才开始翻译。

悬浮翻译始终按“语言 A → 语言 B”的方向翻译，不再根据网页语言自动反向。

### 划词翻译

- 在网页中选中文字后，选区旁会出现“翻译”和“朗读”两个小按钮。
- 点击“翻译”后，会按当前翻译服务和语言方向显示译文。
- 点击“朗读”会用浏览器自带的语音朗读选中的文字。
- 翻译结果右上角也有朗读按钮，可以朗读译文。
- 点击页面空白处或按 Esc 可关闭结果。
- 可在脚本猫配置里关闭划词翻译。

划词翻译默认开启“智能识别”：

- 选中语言 A 时，翻译为 B。
- 选中语言 B 时，翻译为 A。
- 其他语言翻译为语言 B。

例如语言 A 选英语、语言 B 选简体中文：选中英文会翻译成中文，选中中文会翻译成英文。

关闭“智能识别”时，划词翻译会自动识别原文语言，并始终翻译为语言 B。

智能识别会先根据文字使用的字符判断语言（中文、日文、韩文、俄文等可以直接判断）。如果两种语言都用拉丁字母（例如英语和法语），会借助微软或 Google 接口返回的语言检测结果；MyMemory 和自定义接口无法检测时，无法判断的文字默认翻译为语言 B。

朗读使用浏览器自带的 Web Speech API（浏览器语音合成接口，内置的文本转语音功能），不需要额外的翻译服务或接口。能不能发出声音、支持哪些语言，取决于浏览器和系统里安装的语音包。

### 配置

打开脚本猫的脚本管理页面，找到“automatic translation”，点击“配置”按钮修改。保存后刷新网页生效。

配置界面分为三组：

- 常规：默认自动翻译、图标淡化透明度、翻译服务、自定义接口地址、自定义结果字段。
- 悬浮翻译：启用悬浮翻译、语言 A、语言 B。
- 划词翻译：启用划词翻译、智能识别、语言 A、语言 B。

每个翻译功能使用自己的语言设置：悬浮翻译用“语言 A / 语言 B”，划词翻译也用“语言 A / 语言 B”，互不影响。关闭划词智能识别时，自动识别原文语言并始终翻译为语言 B。

脚本猫的配置界面不支持按条件隐藏字段，所以“自定义接口地址”和“自定义结果字段”会一直显示，选择“自定义接口”时填写即可。

关闭“启用悬浮翻译”后，页面右上角的“译”按钮会隐藏，整页翻译也会停止，划词翻译不受影响。需要重新打开时，回到脚本猫的配置界面把“启用悬浮翻译”打开。

可设置：

- 是否默认自动翻译。
- 图标淡化后的透明度。
- 翻译服务。
- 语言 A 和语言 B（悬浮翻译）。
- 是否启用悬浮翻译。
- 是否启用划词翻译。
- 是否启用划词智能识别，以及语言 A 和语言 B。

## 翻译服务

### 默认微软接口

默认“微软翻译”使用 Edge 网页翻译的免鉴权接口：

```text
POST https://edge.microsoft.com/translate/translatetext?from=...&to=...
```

请求体为文本数组，返回 JSON 数组。`from` 省略时自动识别语言。

旧版脚本使用的取 token 接口：

```text
https://edge.microsoft.com/translate/auth
```

微软已在 2026 年 8 月前后下线该接口（返回 404），旧版脚本因此失效。新版脚本改用上面的免鉴权接口，不再需要 token。该接口不是正式公开 API，微软可能调整规则、限流或失效。

### 自定义接口

自定义接口目前只支持简单 GET 请求。接口地址支持：

- `{text}`：要翻译的文本。
- `{from}`：来源语言，可能是 `auto`。
- `{to}`：目标语言。

如果返回 JSON，在“自定义结果字段”里填写结果路径，例如：

```text
responseData.translatedText
```

MyMemory 示例：

```text
接口地址：https://api.mymemory.translated.net/get?q={text}&langpair={from}|{to}
结果字段：responseData.translatedText
```

有道/网易网页接口示例：

```text
接口地址：https://fanyi.youdao.com/translate?doctype=json&type=AUTO&i={text}
结果字段：translateResult.0.0.tgt
```

有道网页接口不是正式开放平台接口，可能限流或失效。正式 API 通常需要 app key、secret 和动态签名，当前自定义接口不能直接生成签名。

## 注意事项

- 翻译内容会发送到你选择的翻译服务，敏感页面谨慎开启。
- 某些动态网页可能出现少量文字未翻译，等待或滚动后可能补翻。
- 如果网站禁止脚本运行，脚本可能无法生效。
- MyMemory 等免费接口可能有频率限制。
- 如果默认微软接口失效，可切换 Google、MyMemory 或自定义接口。
